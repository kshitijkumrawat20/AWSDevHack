# Product Overview: Alexa+ OmniPulse

## Vision
Alexa+ OmniPulse is an autonomous, context-aware multi-service orchestrator built for the Amazon Developer Hackathon (Alexa+ Primary Track & AWS Builder Mini-Challenge). It combines an open-standard Streamable HTTP MCP Server (spec 2025-11-25+), an Agent Skill definition, and an Echo Show-inspired Web Simulator.

## Core Winning Features (Judging Criteria Alignment)
1. **Persistent Cross-Session Memory:** Remembers household health, dietary needs, and preferences across sessions (e.g., knee pain, visiting parents, budget limits).
2. **Autonomous Multi-Service Orchestration:** Single voice/text command triggers sequential and parallel MCP tool calls across Smart Home, Health/Commerce, and Ring Security.
3. **Rich Visual Media & Purchasing Flow:** Returns structured JSON payloads alongside conversational responses to render interactive Product Carousels, Smart Home Status Cards, and 1-Click Voice/Touch Checkout in the simulator.
4. **Proactive Cross-Device Event Trigger (Ring Integration):** Simulates a Ring Doorbell webhook (package delivery or guest arrival) that proactively wakes Alexa+ to verify access and update the user.
